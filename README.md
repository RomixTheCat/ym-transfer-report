# Музыка на новом месте

Статический отчёт о переносе трёх плейлистов из Яндекс Музыки в Spotify.

- 1 986 исходных позиций, 1 975 покрыты.
- 1 982 записи в Spotify: одно попурри развёрнуто в восемь треков.
- 78 позиций с другими версиями, 11 согласованных пропусков.
- 17 записей с региональными ограничениями на момент проверки.

Данные проверены 2 ноября 2026 года. Плейлисты Spotify приватные; публикация отчёта не меняет доступ к ним.

## Просмотр и публикация

Сайт: https://romixthecat.github.io/ym-transfer-report/

Обычные HTML, CSS и JavaScript без сборки и внешних зависимостей. Для локального просмотра: `python3 -m http.server 8765` из этой папки.
GitHub Pages публикует ветку `main`, каталог `/ (root)`. `.nojekyll` отключает обработку Jekyll.

`data.json` содержит только данные отчёта. CSV-файлы находятся в `reports/`.
Поиск и фильтры работают в браузере, без отправки запросов сторонним сервисам.
